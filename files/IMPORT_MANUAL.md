# Anki 手動インポート手順書

## 前提条件

- 既存の「aws sap」デッキ（20枚）を削除する
- 新しい「AWS SAP-C02」デッキ（529枚）をインポートする

---

## 手順1: 既存デッキの削除

1. **Ankiのメイン画面**を開く

2. **「aws sap」デッキ**を右クリック

3. **「削除」**を選択

4. 確認ダイアログで**「削除」**をクリック

---

## 手順2: .apkgファイルのインポート

### 方法A: ダブルクリック（最も簡単）

1. Finderで以下のファイルを探す:
   ```
   /Users/rei.koba/Programing/aws_study/files/AWS_SAP-C02.apkg
   ```

2. **ダブルクリック**

3. Ankiが自動的に開き、インポート画面が表示される

4. **「インポート」ボタンをクリック**

5. インポート完了を待つ

### 方法B: Ankiから手動インポート

1. **Anki Desktop**を開く

2. **ファイル → インポート**を選択

3. 以下のファイルを選択:
   ```
   /Users/rei.koba/Programing/aws_study/files/AWS_SAP-C02.apkg
   ```

4. **「開く」**をクリック

5. **「インポート」ボタンをクリック**

6. インポート完了を待つ

### 方法C: コマンドライン

ターミナルで以下を実行:

```bash
open /Users/rei.koba/Programing/aws_study/files/AWS_SAP-C02.apkg
```

---

## 手順3: 確認

インポート完了後、Ankiのメイン画面で以下を確認:

```
AWS SAP-C02    529
```

✅ カード数が **529** と表示されていればOK！

---

## トラブルシューティング

### Q: まだ20と表示される

**A**: 以下を確認:
1. 本当に「AWS SAP-C02」デッキを見ているか？
2. 「aws sap」デッキを削除したか？
3. インポートボタンを押したか？
4. Ankiを再起動してみる

### Q: 複数のデッキが表示される

**A**: 古いデッキ（カード数が少ない方）を削除する

### Q: インポート画面が表示されない

**A**:
1. Ankiを完全に終了
2. もう一度.apkgファイルをダブルクリック
3. または、Ankiから「ファイル → インポート」で手動インポート
