# Git Push ワークフロー

修正作業が完了したら、以下の手順でGitにpushする。

## 手順

1. `git status` で変更内容を確認する
2. 変更内容のサマリーをユーザーに提示し、以下を確認する:
   - 変更されたファイルの一覧
   - コミットメッセージの案
3. **ユーザーの承認を得てから** `git add`, `git commit`, `git push` を実行する
4. push完了後、結果をユーザーに報告する

## ルール

- **ユーザーの確認なしにpushしてはならない**
- コミットメッセージは日本語で、変更内容を簡潔に記述する
- 不要になったファイルは `_old/` ディレクトリに移動する（削除ではなく移動）
- `_old/` は `.gitignore` に含まれているため、Git管理対象外である

## コミットメッセージのフォーマット

```
[カテゴリ] 変更概要

- 変更点1
- 変更点2
```

カテゴリ例: `feat`, `fix`, `refactor`, `docs`, `chore`
